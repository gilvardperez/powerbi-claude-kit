# Instalar Power BI Claude Kit (instrucciones para agentes de IA)

1. Ejecuta en PowerShell (fuera del sandbox si aplica):
   `powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://gilvardperez.github.io/powerbi-claude-kit/instalar.ps1 | iex"`
2. Revisa la línea `RESULTADO`. Si dice CON PROBLEMAS, corrige lo listado y vuelve a ejecutar (es seguro repetirlo).
3. Pide al usuario reiniciar el agente y activar en Power BI Desktop: Opciones → Vista previa → Power BI Project (.pbip).
